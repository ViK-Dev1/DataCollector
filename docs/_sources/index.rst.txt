DataCollector documentation
===========================

**DataCollector** is a self-hosted Python service that connects to Bybit WebSocket streams
and continuously collects real-time crypto market data — trades, order book snapshots, price, and liquidations —
storing everything into a TimescaleDB time-series database. It is designed to run 24/7 inside a Docker container,
with automatic reconnection in case of crash or exceptions. A Telegram bot runs alongside the collector for 
remote monitoring and control — no need to SSH into the server to check on it.

The full source code is available on `GitHub <https://github.com/vik-dev1/DataCollector>`_.

This documentation's theme and styling were inspired by `Amazon AWS - Boto3 software <https://docs.aws.amazon.com/boto3/latest/>`_.
